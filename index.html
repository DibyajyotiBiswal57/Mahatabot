01 / THE IDEA

A smarter way around.

MAHATABOT/3.0 is a school-built exploration of autonomous movement. Instead of following a fixed path, it checks the space ahead and responds when that path is blocked, turning simple inputs into useful decisions.

Sense the space A forward-facing sensor monitors the path and looks for nearby obstacles.
Choose a direction Control logic compares available space and selects a clearer turn.
Keep moving The drive system follows that direction and scans continuously.
02 / THE LOOP

Sense. Decide. Move.

Autonomy is a repeating cycle, not a one-time instruction. The robot keeps observing its path and adjusting movement as the environment changes.

01 / Input Read the path ahead for immediate obstacles.
02 / Logic Find an opening when the route is blocked.
03 / Output Move, reroute, and scan again in a continuous loop.
